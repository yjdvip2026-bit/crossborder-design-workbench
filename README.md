# Crossborder Design Workbench

跨境电商公司的设计负责人工作台，面向 **Amazon 美国站、TikTok Shop 与 Shopify**，首批支持家居、服饰品类。

**不包含天猫、京东等国内电商平台的业务流程。**

界面产品名：Design Atlas。默认深色主题，支持浅色切换；桌面和移动端均可使用。

## 功能

- **工作台总览**：任务、审核、交付与 AIGC 实验概览。
- **项目与审核**：创建任务、指定平台/品类/负责人、排期、审核反馈及状态管理。
- **设计工具箱**：英寸/厘米批量换算、图片压缩、平台画布参考、AIGC 上线检查、本地化检查和提示词模板。
- **批量图片压缩**：静态 JPEG、PNG、WebP；最长边、画质和目标体积设置；预览、单张下载和 ZIP 打包。
- **压缩文件名后缀**：可编辑、可留空、自动记住；修改后立即影响单张下载和 ZIP 内文件名，无需重新压缩。
- **ZIP 保存文件夹**：支持的浏览器中选择并记住目录，再次导出沿用；可重新选择，重名文件自动编号。
- **设计网址库**：保存网址，按包装、VI、建模、动画或自定义用途分类；支持搜索、编辑、删除、上传截图或设置图片 URL 作为缩略图。
- **趋势雷达**：参考来源、收藏及转设计实验。预置内容是待验证的研究方向，不是实时抓取的行业结论。
- **AIGC 实验室**：记录模型、方法、提示词、人工耗时、费用、产出和审核通过数。
- **品牌与资产库**：保存规范、模板及外部素材链接。
- **设计总结**：根据近七天任务整理复盘，导出 Markdown。
- **个人/团队空间**：分别保存浏览器本机数据；支持 JSON 备份及恢复。

## 本地运行

这是不依赖构建工具的静态网页。安装 Python 3 后：

```bash
git clone https://github.com/yjdvip2026-bit/crossborder-design-workbench.git
cd crossborder-design-workbench
python -m http.server 8765 --directory dist
```

访问 <http://localhost:8765>。也可以把 `dist/` 部署到静态网站托管服务。

建议通过 `localhost` 或 HTTPS 运行。直接双击 HTML 文件可能影响浏览器存储和文件访问能力。

## ZIP 保存路径如何使用

1. 打开“设计工具箱 → 批量图片压缩”。
2. 选择图片并设置压缩参数、文件名后缀。
3. 点击“选择保存文件夹”，授权访问该目录。
4. 点击“开始压缩”，完成后点击“打包下载 ZIP”。
5. 后续导出默认写入已选目录；只有重新选择才更改位置。

目录句柄保存在当前站点的 IndexedDB 中。浏览器重启、权限被撤销或系统策略变化时，可能需要再次允许写入；清理站点数据会忘记目录。网页只能显示目录名称，不能读取操作系统的完整绝对路径。

文件夹选择依赖 File System Access API，通常需要独立的桌面版 Chromium 浏览器（例如 Chrome / Edge）与安全上下文。Safari、Firefox、移动端或内嵌聊天页面可能不支持。此时会说明限制并使用浏览器的普通下载位置；普通下载位置由浏览器设置决定。权限或保存失败时，也可显式改用普通下载。

同一天多次保存同名 ZIP，会产生 `… (2).zip` 等新文件，避免直接覆盖旧文件。单张图片下载仍遵循浏览器的下载设置。

## 网址与缩略图

- 在侧栏进入“设计网址库”，点击“保存网址”。
- 输入名称、HTTP/HTTPS 网址、用途分类与备注。
- 默认尝试加载该网站自身的 `/favicon.ico`；加载失败时显示名称首字母。
- 可上传 JPEG/PNG/WebP 截图作为卡片缩略图，或填写外部图片链接。
- 上传图片在浏览器本地缩小后保存，不上传图片服务器。它不是自动网页截图服务。
- 在“管理分类”中添加自定义分类。分类内仍有网址时，需先移动网址才能删除分类。
- 个人与团队空间的网址彼此独立，并包含在工作区 JSON 备份中。

## 数据与当前边界

- 业务记录、网址及缩略图保存在当前浏览器的 `localStorage`；目录授权句柄保存在 `IndexedDB`。
- 图片压缩和上传缩略图处理均在本地运行。站点图标、外部图片链接及原始参考链接仍会向对应网站发送正常浏览请求。
- 换浏览器、换站点域名、换设备或清除站点数据，不会自动迁移数据；请定期导出备份。
- 浏览器存储有容量限制；大量缩略图可能占满空间。保存失败时会提示，不会把失败报告成成功。
- 团队空间目前是本机协作流程预览，尚无成员邀请、权限控制或多人同步。
- 未接入实时行业抓取、销售/广告指标和付费 AI 生成服务。
- 示例数据可通过“数据与工作空间”清空；清空前可先导出备份。
- 源码仓库不包含任何用户浏览器记录、上传图片、已授权目录或密钥。

## 项目结构

```text
dist/
  index.html              页面骨架与主题初始化
  style.css               深浅主题、响应式布局和组件样式
  app.js                  核心工作台、压缩、换算、备份等功能
  zip-save.js             保存目录、目录记忆、授权与 ZIP 写入
  link-library.js         分类网址库、缩略图与备份验证
  assets/favicon.svg      网站图标
docs/
  VALIDATION.md           验证流程与验证范围
.openai/
  hosting.example.json    静态托管配置示例，不绑定现有站点
CHANGELOG.md
```

## 静态部署

把 `dist/` 设为发布目录即可。工作台使用 URL hash 路由（如 `#tools`、`#links`），不需要服务端重写。

`.openai/hosting.example.json` 仅为配置模板。复制或部署到新的 Sites 项目时，应使用新项目返回的 ID，不要复用其他项目的身份配置。
