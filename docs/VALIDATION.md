# 验证记录

## 2026-11-06

使用 Playwright 驱动 Chromium，在 localhost 安全上下文验证。界面检查覆盖深色/浅色及 1440px/390px 两种宽度。

### ZIP 保存文件夹

- 使用真实浏览器 `FileSystemDirectoryHandle` 和 IndexedDB 验证句柄持久化及刷新恢复。
- 自动化中的系统文件夹选择器由测试替身返回浏览器 OPFS 目录；创建、写入、关闭与读取文件使用真实浏览器文件 API。
- 验证首次保存、连续保存沿用同一目录、重名 ZIP 自动编号、刷新后保存、更换目录。
- 验证取消选择保留原目录、权限拒绝时不静默写入、显式选择浏览器普通下载。
- 验证不支持 File System Access API 的浏览器路径仍能普通下载 ZIP。
- 对生成 ZIP 检查条目文件名和 CRC。

验证边界：没有自动操作真实操作系统的目录选择对话框，也没有验证所有浏览器/聊天内嵌环境的权限策略。实际授权弹窗仍由用户的浏览器控制。

### 设计网址库

- 新建网址，自动补齐 HTTPS，刷新后保留。
- 新建自定义用途分类，编辑分类、筛选与搜索。
- 上传图片在本地缩小并保存为 WebP 缩略图。
- 修改为外部图片链接，取消自定义缩略图，图片不可用时回退。
- 个人和团队空间记录隔离。
- JSON 备份验证包含网址、分类和图片数据；旧备份缺少新字段时仍可导入。
- 深浅主题、桌面/手机无横向溢出，无 JavaScript 运行时错误。

### 既有功能回归

尺寸换算、任务保存/状态、趋势转实验、后缀编辑、图片压缩、ZIP 下载、复盘导出及 JSON 恢复保留既有功能。

## 手动验收建议

1. 用独立的桌面 Chrome/Edge 打开 HTTPS 工作台。
2. 选取真实文件夹，压缩两张图片并打包；在文件管理器确认 ZIP。
3. 刷新后再次打包，确认沿用原文件夹且旧 ZIP 没被覆盖。
4. 更换目录后再保存，确认新位置；如重启浏览器后出现授权提示，重新允许。
5. 网址库添加包装/VI/建模/动画网址，上传截图，刷新确认。
6. 导出 JSON，在同一空间导入并确认网址和缩略图恢复。
